## Learning by Example

### Example-Based Learning Path

#### For Beginners

Start with the **[FIFA Dataset Analysis]({{% relref "fifa-analysis" %}})** example to understand:
- How to explore a new dataset
- How to generate summary statistics
- How to create and run a preprocessing pipeline
- How to verify results

#### For Intermediate Users

Study the **[Numeric Columns]({{% relref "numeric-columns" %}})** and **[Text Columns]({{% relref "text-columns" %}})** examples to learn:
- Specific operation syntax
- How to apply operations to different column types
- How to chain multiple operations

#### For Advanced Users

Combine techniques from all examples to:
- Create complex preprocessing pipelines
- Handle different data types in one workflow
- Automate repetitive tasks
